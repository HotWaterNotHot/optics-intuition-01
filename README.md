# 透明的尽头是白色 · 光学直觉 #01

**在线阅读**：https://hotwaternothot.github.io/optics-intuition-01/ （首次发布后生效）

水和空气都是透明的。把光路上的界面数量乘以一亿倍，你得到的不是更透明——是雪白。

这是一个可交互的光学直觉页面：拖动滑块，亲手把"透明"拖成"白色"，看直线透过率的指数雪崩，
再带着这个直觉理解雪、云、啤酒沫为什么是白的。

- 交互核心：界面数量 N（10⁰–10⁶，对数滑块）× 单界面反射率 p → 直线透过率 T = (1−p)^N
- 蒙特卡洛光线演示 + 双对数透过率曲线 + 真实世界数量级锚点（窗玻璃/气泡水/磨砂/啤酒沫/雪/云）
- 无框架、无依赖、无构建步骤：一个 index.html，手机端可用

## 本地运行

python -m http.server 8000

## 模型口径

- 垂直入射 Fresnel 反射率：R = ((n₂−n₁)/(n₂+n₁))² ≈ 2.0%（空气-水界面）
- 泡沫中平均单界面反射率取 p = 6%（斜入射 + 全反射抬升，可调 2–25%）
- 详细假设见页面底部"简化模型声明"
